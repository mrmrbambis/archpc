## Контрольные вопросы

1. Что такое командная строка?
Командная строка (терминал, консоль, shell) — это текстовый интерфейс для взаимодействия пользователя с операционной системой.
Основные характеристики:
Пользователь вводит команды в текстовом виде
Система выполняет команду и выводит результат
Позволяет автоматизировать задачи через скрипты
Требует знания синтаксиса команд, но даёт больше контроля и гибкости, чем графический интерфейс
Примеры интерпретаторов: Bash (Linux), Zsh (macOS/Linux), Command Prompt и PowerShell (Windows).

5. Возможно ли полноценное управление системой только через командную строку?
Да, возможно, и во многих случаях — даже предпочтительнее.Обоснование:
Все системные операции (установка ПО, настройка сети, управление пользователями, мониторинг) доступны через команды
Скрипты позволяют автоматизировать сложные задачи (бэкапы, развёртывание, логирование)
На серверах часто нет графического интерфейса — управление только через CLI
CLI потребляет меньше ресурсов и работает быстрее
Возможность удалённого управления через SSH без передачи графического интерфейса

6. Чем отличается командная строка Windows от MS-DOS?
Командная строка Windows (cmd.exe) — это лишь встроенное консольное приложение внутри современной графической ОС, тогда как MS-DOS (Microsoft Disk Operating System) — это полноценная, самостоятельная однозадачная операционная система

7. Примеры команд в других ОС
Интерпретатор команд (shell) — это программа, которая считывает вводимые пользователем команды и передает их операционной системе на выполнение.В различных операционных системах используются свои стандартные и альтернативные командные оболочки:
Windows:cmd.exe (Command Prompt) — классический интерпретатор, унаследовавший многие команды от MS-DOS.PowerShell — современная мощная объектно-ориентированная оболочка для автоматизации административных задач.Linux / Unix / macOS:Bash (Bourne-Again SHell) — стандартный интерпретатор для большинства дистрибутивов Linux и macOS (по умолчанию).Zsh (Z Shell) — продвинутая оболочка со встроенными механизмами автодополнения; установлена по умолчанию в современных версиях macOS.sh (Bourne shell) — исторически первая стандартная оболочка для Unix-подобных систем.Fish (Friendly Interactive Shell) — оболочка, созданная для максимального удобства, подсветки синтаксиса и интерактивных подсказок.
