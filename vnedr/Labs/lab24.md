## КОНТРОЛЬНЫЕ ВОПРОСЫ
. Что считается файлами в ОС LINUX?
В Linux всё является файлом. К файлам относятся:
Обычные файлы (текстовые, бинарные, скрипты)
Каталог (директория) - специальный файл, содержащий список других файлов
Символические и жёсткие ссылки
Специальные файлы устройств (в /dev)
Сокеты (сетевые и доменные)
Именованные каналы (FIFO)
Процессы (в /proc)
2. Объясните назначение связей с файлами и способы их создания
Назначение связей (links):
Жёсткие ссылки (hard links) - позволяют одному файлу иметь несколько имён в пределах одной файловой системы. Все ссылки указывают на один inode.
Символические ссылки (symbolic/soft links) - аналог ярлыков в Windows, указывают на путь к файлу, могут ссылаться на файлы в других файловых системах и на каталоги
# Жёсткая ссылка:
ln исходный_файл имя_ссылки

# Символическая ссылка:
ln -s исходный_файл имя_ссылки

3. Что определяет атрибуты файлов и каким образом их можно просмотреть и изменить?
Атрибуты файлов определяют:
Права доступа (чтение r, запись w, выполнение x) для владельца, группы и остальных
Тип файла (обычный, каталог, ссылка и т.д.)
Владельца файла и группу
Размер файла
Время создания, модификации и последнего доступа
Специальные атрибуты (immutable, append-only и др.)
Просмотр атрибутов:

ls -l имя_файла          # основные атрибуты
stat имя_файла           # подробная информация
lsattr имя_файла         # специальные атрибуты

chmod [права] файл       # изменение прав доступа
chown владелец файл      # смена владельца
chgrp группа файл        # смена группы
touch файл               # изменение времени доступа
chattr [атрибуты] файл   # изменение специальных атрибутов

4. Какие методы создания и удаления файлов, каталогов Вы знаете?
Создание файлов:
touch имя_файла          # создание пустого файла
echo "текст" > файл      # создание файла с содержимым
cat > файл               # ввод текста с клавиатуры
cp источник копия        # копирование файла 

rm имя_файла             # удаление файла
rm -f имя_файла          # принудительное удаление
unlink имя_файла         # удаление ссылки на файл

mkdir имя_каталога       # создание одного каталога
mkdir -p путь/к/каталогу # создание дерева каталогов

rmdir имя_каталога       # удаление пустого каталога
rm -r имя_каталога       # рекурсивное удаление каталога с содержимым
rm -rf имя_каталога      # принудительное рекурсивное удаление
